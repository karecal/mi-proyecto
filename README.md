# 💻 Circle Agency Website

## 📌 Description

This project is a responsive website for a fictional digital agency called **Circle Agency**.

The goal of the project was to build a multi-page website using HTML, CSS and JavaScript, focusing on layout, responsiveness and basic interactivity.

---

## 🚀 Features

- Responsive design (desktop & mobile)
- Navigation bar with hamburger menu
- Multiple pages:
  - Home
  - Project details
  - Contact page
- Contact form with validation
- Interactive elements with JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, media queries)
- JavaScript (DOM manipulation & events)

---

## ⏱️ Development Process

The project was developed in approximately 6 / 9 [ days / hours] as part of a bootcamp practice.

Main steps:
1. Structure with HTML
2. Styling with CSS
3. Responsive design
4. JavaScript interactions (menu, form validation)

---

## ⚠️ Challenges & Solutions

### 1. Responsive Navigation (Burger Menu)
- **Problem:** The mobile menu was not displaying correctly.
- **Solution:** Unified the navbar structure across all pages and fixed CSS/JS inconsistencies.

### 2. Relative Paths
- **Problem:** Some links and assets were broken between pages.
- **Solution:** Adjusted relative paths depending on folder structure.

### 3. Form Validation
- **Problem:** Handling validation errors properly.
- **Solution:** Added JavaScript functions to validate inputs and show error messages.
